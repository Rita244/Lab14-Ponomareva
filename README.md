## Контрольные вопросы

1. WriteAllText перезаписывает файл целиком, AppendAllText — дописывает в конец, старое не стирает

2. Массив строк string[] — с ним можно работать как с обычным массивом (.Length, индексы, foreach)

3. using автоматически закрывает файл в конце блока, даже при ошибке. Без него файл останется «занятым» и данные могут не сохраниться

4. using — это тот же try-finally, только короче: закрытие происходит гарантированно, как в finally

5. Сам ставит правильный разделитель пути под ОС (\ или /), а ручная склейка через + может сломаться на другой системе

6. FileNotFoundException — файл не найден; IOException — общая ошибка ввода-вывода (файл занят, нет прав и т. п.). Первый — частный случай второго, поэтому его catch ставят раньше
